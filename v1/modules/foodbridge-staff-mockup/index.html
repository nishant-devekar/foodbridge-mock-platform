Workforce Management

Disposable HTML prototypes for the Foodbridge Module Staff Management module. This round is a fidelity port of the live storefront route /our-staff — same structure, same classes, same edge cases — driven entirely by seed data. Nothing here calls a real API, and nothing here is imported by development/.

Known divergences from the live app

Recorded deliberately rather than papered over.

Three, all documented in the addendum:
  • Google Sheet subsystem not ported. Export/sync toolbar, iframe sheet view and diff engine are excluded by decision. On the reference tenant its feature flags are off, so it renders nothing there either — the toolbar slot is present but empty.
  • Sidebar submenus start collapsed except Product Master, matching the reference screenshot. The live default is useState(true) — every submenu expanded on first paint. Flip initiallyOpen in the seed to get the live default.
  • “Workforce Management” is a tenant label, not a hardcoded string. Live it comes from useMenuLabel("our-staff") reading storefrontMenus; the same page reads “Our Staff” on a tenant that hasn’t renamed it. It is seeded here.
Governed by AMDS. Discovery is HTML-only and disposable (SPEC §3.1) — it produces the decisions that become the SSOTs under development/sources-of-truth/, and is never imported by development/. Working rules: instructions/addendum-001-working-rules.md.
